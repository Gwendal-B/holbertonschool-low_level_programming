
# File I/O Project

## Description
This project covers file input/output operations in C programming, including reading from and writing to files.

## Learning Objectives
- Understand file descriptors
- Learn how to open, close, read, and write files
- Work with system calls: `open()`, `close()`, `read()`, `write()`
- Handle file permissions and modes
- Manage errors properly

## Project Structure
```
file_io/
├── README.md
└── [source files]
```

## Key Concepts
- **File Descriptors**: Integer references to open files
- **System Calls**: Low-level functions for file operations
- **Flags**: `O_RDONLY`, `O_WRONLY`, `O_CREAT`, `O_TRUNC`
- **Error Handling**: Using `perror()` and checking return values
